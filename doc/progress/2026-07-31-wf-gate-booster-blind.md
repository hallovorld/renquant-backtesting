# GOAL-6 — the WF gate's admission scope is booster-blind, executed rather than read

**Date:** 2026-07-31 · `renquant-backtesting` · GOAL-6 evaluation path

Characterisation tests. **No behaviour change.** They pin what is in force today so it
cannot move silently, and they turn a source-reading claim into an executed one.

## The mechanism, in three lines of the real code

`runner.inspect_artifact_usage` — on the production path
(`strategy_config.walkforward.enabled = true`) returns
**`candidate_artifact_used: False` unconditionally**. That is deliberate: a current
artifact cannot be replayed into old sim windows without look-ahead, so the gate
validates the *retraining recipe* instead.

`runner.py:3625` then decides scope:

```python
validation_scope_ok = bool(artifact_usage.get("candidate_artifact_used")) or bool(
    artifact_usage.get("recipe_validated"))
```

`False or recipe_validated` — so on the production path admission rides **entirely** on
`recipe_validated`.

And `recipe_match.recipe_projection` — the thing the fingerprint is taken over — is
exactly `kind`, `feature_cols`, `feature_norm_kind`, the contract **keys**, `label_col`,
`lookahead_days`, and the semantic learner params. **No learned parameter is in it.**

## What that means, measured

Two artifacts that differ **only** in their trained booster carry the **same**
fingerprint `[VERIFIED — tests/test_wf_gate_recipe_admission_is_booster_blind.py]`. Put
artifact A in the manifest, hand the gate candidate B, and `recipe_validated` is `True`:

> **a candidate is admitted in scope on evidence generated by a different booster, and
> nothing on this path scores the candidate's own weights.**

This is why GOAL-6's Stage-2 retrain has no evaluation path, and it is the same reason
GOAL-4's ensemble could not be admitted even if it were better: **the gate cannot tell
the two apart.** One defect, two lanes.

## Anti-vacuity

If `recipe_validated` were hardcoded `True`, the headline test above would pass and this
file would prove nothing. So four genuinely different **recipes** — a dropped feature, a
different `kind`, a different label horizon, a different `eta` — must each be **refused**,
and are. Plus: one mismatching manifest row sinks the whole manifest; a missing, absent
or empty manifest is a **refusal**, never a skip.

13 tests pass.

## What this does NOT do

It does not fix anything. Closing the gap needs a decision that is not mine to take
alone: either the gate scores the candidate's booster on a leak-free window it *can*
replay, or admission stops claiming to be about the candidate at all and says so in its
own verdict string. Both are design changes to a capital gate.
